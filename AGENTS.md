# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.

## Role Terminology

- In user-facing copy, use the most specific established role: `Global admin`, `Landlord`, `Tenant`, or `Applicant`.
- Do not use `client` or `clients` for people in product copy, routes, or domain names. Use the applicable role, or `application` / `account` when a screen legitimately spans multiple roles.
- `Agent` and `Builder` remain valid role names where applicable.
- Technical terms such as React client components, HTTP clients, and Azure Cosmos clients are exempt from this terminology rule.
